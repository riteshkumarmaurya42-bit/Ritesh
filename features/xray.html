🔬 How the grade is computed

Six weighted dimensions — Activity (25%), Maintenance (20%), Popularity (15%), Community (15%), Documentation (15%) and Resilience (10%). Star counts use a logarithmic curve so a 40k-star giant does not flatten everything else, and staleness decays linearly from "pushed this week" to "untouched for a year". Resilience blends the bus factor with a Gini coefficient of contribution inequality, so a repo with 300 contributors where one person writes 95% of the code scores honestly. The whole engine lives in js/xray-engine.js — dependency-free, unit-tested, and it also powers the CLI: node bin/xray.js facebook/react.
