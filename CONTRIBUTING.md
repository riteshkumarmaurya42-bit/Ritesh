# Contributing to Ritesh Portfolio ⚡

Thanks for wanting to contribute! This portfolio is meant to be a playground.

## How to Contribute

1. **Fork & Clone**
   ```bash
   git clone https://github.com/your-username/Ritesh.git
   ```

2. **Create Branch**
   ```bash
   git checkout -b feature/your-awesome-idea
   ```

3. **Make Magic**
   - Add a new game to Arcade Zone
   - Add a new tool to DevTools Hub
   - Improve particle effects
   - Add WebGL shaders
   - Create new easter eggs

4. **Test Locally**
   ```bash
   npx serve . -l 3000
   ```

5. **Commit & PR**
   ```bash
   git commit -m "feat: add awesome feature"
   git push origin feature/your-awesome-idea
   ```
