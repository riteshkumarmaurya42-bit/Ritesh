# Code of Conduct

## Our pledge

Everyone participating in this project — in issues, PRs, discussions, or any
other channel — is expected to keep the space welcoming and respectful.

## Our standards

**Behaviors that help:**

- Being kind and patient with newcomers
- Giving and accepting constructive feedback gracefully
- Focusing on the code and ideas, not the person

**Behaviors that won't be tolerated:**

- Harassment, discriminatory jokes or language, or personal attacks
- Publishing others' private information without consent
- Any conduct a reasonable person would consider inappropriate in a
  professional setting

## Enforcement

Problems can be reported privately by opening a security advisory or
contacting the maintainer via a GitHub issue marked as off-topic.
All reports are reviewed and handled with discretion.
